# 東洋医学バランスチェック 対応表ドラフト v0.1.1

**作成日**: 2026-07-12(v0.1.1 同日改訂)
**ステータス**: 専門家監修前のドラフト(AIによる古典的五行理論ベースの叩き台 + AI相互レビュー反映済み)
**用途**: アプリの診断ロジックの元データ。監修・修正後に `data/mapping.json` に反映してアプリに組み込む。

---

## 監修者の方へ(お願い事項)

本表は、中医学の古典的な五行学説・臓象学説(五竅・五主・五志・五味など)をもとに、
一般向けセルフチェックアプリ用に**簡略化**して作成した叩き台です。以下の観点でご確認ください。

1. **対応の妥当性**: 部位×症状 → 臓腑(証)の対応が、簡略化として許容範囲か
2. **根本原因の推論**: 相生・相克をたどる推論(第2章のルール)が乱暴すぎないか
3. **安全性**: 「この症状はセルフチェックで扱うべきでない(受診勧奨すべき)」ものの指摘
4. **改善法**: 食養生・生活習慣の内容が一般向けとして適切か
5. 各行の右端「監修メモ」欄に、修正・削除・コメントを自由にご記入ください

> **アプリ上の免責方針**: 本アプリは「診断」ではなく「バランスチェック」と表記し、
> 「医療診断に代わるものではありません。症状が強い場合・続く場合は医療機関を受診してください」を常時表示します。
> また第5章の受診の目安(レッドフラグ)を、結果画面の冒頭とチェック開始前の両方に表示します。

## 第2章 根本原因の推論ルール(アプリの「循環構造」ロジック)

症状の出た部位から直接対応する臓腑を特定した後、以下のルールで**根本原因の候補**を提示します。
アプリでは五行の円環図上に「根本原因の候補」→「症状の窓口の臓腑」を矢印で表示します。

### 相生(そうせい)= 母子関係: 木→火→土→金→水→木

- **ルールA(虚証パターン)**: 機能低下・冷え・だるさ系の症状は「母の臓の弱り」を根本原因候補とする
  (母病及子 / 虚すればその母を補う)
  - 例: 目のかすみ(肝血虚)→ 母である**腎**(水生木)の不足を候補に

### 相克(そうこく)= 抑制関係: 木克土、土克水、水克火、火克金、金克木

- **ルールB(実証パターン)**: 痛み・熱・張り系の症状は「克してくる臓の過剰(相乗)」を根本原因候補とする
  - 例: ストレス性の胃痛(脾胃)→ 克してくる**肝**の気の高ぶり(肝気犯胃・木乗土)を候補に

### 相生の失調(陰の滋養不足)

- **ルールC(陰虚陽亢パターン)**: のぼせ・上部の熱・高ぶり系の症状は「母にあたる臓の陰(潤い)の不足が、子の高ぶりを潤し抑えられていない」ことを根本原因候補とする(相生の失調: **水不涵木** など。母病及子の一型)
  - 例: 目の充血・張るような頭痛(肝陽上亢)→ 母である**腎**の陰の不足(水不涵木)を候補に

### 用語の補足(v0.1.1 で整理)

- **相乗(そうじょう)**: 相克が行きすぎて相手を傷めること(例: 木乗土 = ストレスで肝が脾胃を攻める)
- **相侮(そうぶ)**: 本来克される側が逆に克す側を攻め返すこと(例: **木火刑金** = 肝火が強すぎて、本来木を抑えるはずの金(肺)を逆に攻める)
- v0.1 ではルールCを「相克(相侮的状況)」と誤って分類していました。水は木を克す関係ではなく母子関係(水生木)のため、**水不涵木は相生の失調**として再定義しています。

> **監修ポイント**: 上記3ルールは一般向けの簡略化です。「このルールをこの症状に適用するのは不適切」という箇所があればご指摘ください。

## 第5章 受診勧奨の条件(セーフティネット)

以下に該当する場合は、チェック結果よりも先に「医療機関の受診」を促す表示を行います。
**v0.1.1 での実装状況**: この一覧は①チェック開始画面(部位選択の下の折りたたみ)と②結果画面の冒頭カードに常時表示。
加えて、耳-2(急な耳鳴り)・腰-3(急な腰痛)には症状別の受診勧奨文、膝-2には片脚急性むくみへの注意文を個別表示。
**監修者の方へ: 追加すべき条件があればご指摘ください。**

- 急に始まった激しい痛み(頭・胸・お腹・腰)
- 発熱を伴う症状
- しびれ・麻痺・ろれつが回らないなどの神経症状
- 血が混じる症状(血便・血尿・咳に血が混じるなど)
- 片脚だけ急にむくみ、痛みや赤みを伴う場合
- 急激な体重減少を伴う場合
- 2週間以上続く・悪化し続ける症状全般(結果画面・フッターに常時注記)

### 6-3. 問診(7問)による絞り込み

いつから/きっかけのストレス/押さえ込んだ感情/悪化条件/睡眠/食欲の6問+内省用の1問。
各回答に候補パターンへの重み(1〜2点)を設定し、**部位からの候補(主表示3点・その他1点)に加算**して最有力を決めます。
候補にないパターンが問診だけで選ばれることはありません(安全側の設計)。重みの妥当性をご確認ください
(重みの一覧は `data/mapping.json` の `interview` セクション。必要なら表に起こします)。

押さえ込んだ感情と五志の対応: 怒り→肝(P02/P03)、悲しみ→肺(P08/P09)、思い悩み→脾(P05/P06)、恐れ→腎(P10/P11/P12)。
