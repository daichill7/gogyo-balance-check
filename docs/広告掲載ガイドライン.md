# 五行バランスチェック 広告掲載ガイドライン(内部規程 v1.0)

**作成日**: 2026-07-16
**用途**: 広告掲載可否の審査基準・料金体系の内部規程。応募があった際はこの基準で判断する。
将来、対外向け「広告掲載のご案内」ページ・提案書のベースにする。

---

## 1. メディア概要(提案時に使う情報)

- 媒体: 五行バランスチェック(https://gogyo-balance-check.netlify.app)
- 内容: 東洋医学ベースのセルフチェック+人体・ツボの学習アプリ
- ユーザー層: 健康・東洋医学・セルフケアに関心のある層(=広告主にとって濃い見込み客)
- 実績数値: Cloudflare Web Analytics のPV・訪問者数を提案時に添付(毎月更新)

## 2. 掲載可否の審査基準

### ✅ 掲載できる業種・商材(親和性が高い)
- 鍼灸院・整体院・接骨院・マッサージ(国家資格者の施術所)
- 漢方薬局・薬膳教室・お茶/ハーブティー販売
- ヨガ・ピラティス・気功・瞑想スタジオ
- 温浴施設・サウナ・よもぎ蒸し
- 健康的な食品(産直野菜・発酵食品など)
- 書籍・講座(東洋医学・栄養学・セルフケア系)

### ❌ 掲載できないもの
- 医薬品的な効能効果をうたう健康食品・サプリ(**薬機法違反リスク**)
- 「がんが治る」「飲むだけで痩せる」等、効果を断定・保証する表現を含むもの
- 医療機関を受診しないことを勧める内容(当アプリの安全方針と矛盾)
- 情報商材・マルチ商法・投資勧誘・出会い系・ギャンブル
- 公序良俗に反するもの、宗教・政治団体の勧誘
- 競合の占い/診断アプリ(個別判断)

### 表現の審査ポイント(掲載OKの業種でもここをチェック)
1. 効能の**断定表現がないか**(「治る」「必ず」「絶対」→NG。「〜をサポート」「〜の方に人気」→OK)
2. ビフォーアフター写真で効果を保証していないか
3. 施術所の場合、資格・所在地・料金が明記されているか(実在確認)
4. リンク先ページが安全か(SSL・過剰なポップアップがないか)

### 掲載時の共通ルール
- 広告には必ず **「PR」表記** を付ける(ステマ規制対応。現在の広告枠は自動でPR表記)
- 診断結果の信頼性を守るため、**結果画面の「受診の目安」より上には広告を置かない**
- 掲載後でも、苦情・問題があれば運営判断で掲載を停止できる(規約に明記)

## 3. 料金体系(v1・小規模メディア妥当水準)

| 枠 | 位置 | 料金(月額・税込) | 備考 |
|---|---|---|---|
| A: フッターバナー | 全画面の下部(現在の枠) | **3,000円** | ローテーション表示(最大3社) |
| B: 結果画面スポンサー | 診断結果の最下部「このアプリのスポンサー」 | **8,000円** | 1社限定・将来開放 |
| モニター掲載 | A枠 | **初月無料** | 掲載実績づくり。感想・掲載例の使用許可をもらう |

- 月間PVが伸びたら改定(目安: 月1万PV超で A:5,000円 / B:15,000円)
- 支払い: 銀行振込(前払い・月単位)。継続は自動更新せず毎月確認から始める
- 制作: バナーはテキスト+リンクの標準フォーマット(画像バナーは+2,000円で運営が作成代行)

## 4. アフィリエイト方針(当面のメイン収益)

- **楽天アフィリエイト / Amazonアソシエイト**を導入し、診断結果に合った商品(お茶・食材・書籍など)を自動表示する
- 商品リンクにも「PR」表記を付ける
- 表示する商品は**診断結果の食養生と整合するもののみ**(なんでも表示しない)
- 薬機法に配慮し、商品説明で効能を追記しない(商品名+価格のみ)

## 5. 掲載までの流れ

1. アプリ内フォーム「広告掲載のご相談」から応募
2. 運営が本ガイドライン第2章で審査(3営業日目安)
3. 掲載内容(テキスト・リンク先)の確認 → 入金 → 掲載開始
4. 掲載月の翌月に表示回数の簡易レポートを送付(Cloudflare解析ベース)
