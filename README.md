# 五行バランスチェック

東洋医学(五行)の考え方で症状部位から根本原因の候補をたどり、食養生・生活習慣のセルフケアにつなげるWebアプリ。

- 本番: https://gogyo-balance-check.netlify.app
- 症状チェック(ルールベース) / 四柱推命「精霊」50タイプ / 五行の村(自前チャット) / 写真歪みチェック(端末内AI)

**開発に参加するAI・人は、まず [PROJECT.md](./PROJECT.md) を読むこと。** 目的・機能一覧・データ設計・デザイン思想・今後の予定はすべてそこに集約されています。

## 起動(ローカル)

ビルド不要。このフォルダを任意の静的サーバーで配信するだけ。

```bash
python3 -m http.server 8750
```

村サーバー(任意): `server/village-worker/` で `npx wrangler dev`

## 注意

- 「診断」と言わない(バランスチェック表記)・免責常時表示
- `data/mapping.json` と `docs/対応表ドラフト_v0.1.md` は1対1整合が必須
- デプロイは最小回数でまとめて(Netlifyクレジット制)
